# ReTryPay Delivery Skill

When assigned work, first identify: affected domain invariant, required tests, and whether the work touches external provider/PII boundaries.

Use this workflow:
1. Read the nearest documentation and contracts.
2. State a short implementation plan and acceptance criteria.
3. Change schema/domain logic before UI.
4. Add tests before or with implementation.
5. Run relevant checks.
6. Report changed files, tests executed, known limitations, and next dependency.

Reject or escalate requests that conflict with `AGENTS.md` non-negotiable rules. Prefer a small vertical slice over untested framework expansion.
